# 政务信息公开申请审查系统

辅助政府工作人员处理市民提交的《政府信息公开》申请：判断申请是否符合
《中华人民共和国政府信息公开条例》规定，并与本地判例语料进行比对，输出处理建议与 HTML 报告。

## 功能
- **合规初筛**：自动检查申请人身份信息、内容明确性、是否触及不予公开情形、是否涉嫌滥用申请，给出合规评分与法条依据。
- **判例比对**：将申请与 `precedents/` 目录下的裁判文书（来自中国裁判文书网等）做相似度匹配，列出参考判例与裁判要旨。
- **建议生成**：综合检查与判例，输出可操作的处理建议（补正 / 审查 / 予以公开）。
- **HTML 报告**：自包含报告，可直接浏览器打开，含评分、问题清单、判例表、综合建议与免责声明。

## 快速开始
```bash
cd govinfo-review
python main.py --interactive          # 交互式粘贴申请
# 或
python main.py -i samples/申请示例.txt -o 报告.html
```

## 关于 wenshu.court.gov.cn（中国裁判文书网）
- 该站有反自动化机制与用户协议限制，**不建议**自动化批量抓取。
- 本程序**不硬编码任何账号密码**；如需调用 `wenshu_client.py`，凭证须从环境变量读取（见 `config.py`）。
- **推荐做法**：人工在网站检索"政府信息公开"相关文书，导出为 JSON（字段见下）或 TXT，放入 `precedents/` 目录即可参与比对。

### 判例语料格式
- `*.json`：`{"title","court","date","doc_id","tags":[],"outcome","content"}`
- `*.txt`：纯文本裁判文书，文件名作为标题

## 关于账号凭证的重要提醒
您的裁判文书网账号密码**绝对不要写入任何代码或配置文件**。本程序所有敏感信息均通过
环境变量（如 `WENSHU_USERNAME`、`WENSHU_PASSWORD`）注入，且核心功能默认不依赖该网站。

## 免责声明
本工具输出仅为辅助性合规参考，不构成正式行政决定。最终答复须由经办人员依法作出。
判例比对基于本地语料，不构成穷尽检索。
